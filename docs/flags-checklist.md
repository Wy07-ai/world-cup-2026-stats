# Daftar Kebutuhan Bendera (SVG)

Daftar ini hanya mencatat kebutuhan; berkas SVG **belum** dibuat (di luar wewenang Claude #4). Lokasi tujuan: `public/flags/`.

## Aturan berkas
- Ukuran maksimal **5 KB per berkas SVG** (PRD Bab 8.2; kutipan ini belum dapat dicocokkan karena `docs/master-prd.md` masih placeholder).
- Nama berkas **wajib huruf kecil** (mis. `usa.svg`, bukan `USA.svg`). Sistem berkas server Linux membedakan huruf besar dan kecil, sehingga `USA.svg` dan `usa.svg` dianggap berkas berbeda dan bendera akan "hilang diam-diam" di UI.
- Nama berkas harus persis `{id huruf kecil}.svg` agar cocok dengan `Team.flagUrl` (`/flags/{id}.svg`).
